# SatModelPoints_MotorLAB

## Summary
Resolution of the Lab saturation model for BPM, BPMOR and SYNCREL motors. When custom is selected then the same resolution will be used for the FEA map loss model.

## Description
Resolution of the Lab saturation model for BPM, BPMOR and SYNCREL motors. When custom is selected then the same resolution will be used for the FEA map loss model.
