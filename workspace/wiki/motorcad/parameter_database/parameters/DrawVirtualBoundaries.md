# DrawVirtualBoundaries

## Summary
When true, virtual boundaries will be drawn in the geometry editor (e.g. boundary between rotor back iron/embedded magnet pole)

## Description
When true, virtual boundaries will be drawn in the geometry editor (e.g. boundary between rotor back iron/embedded magnet pole)
