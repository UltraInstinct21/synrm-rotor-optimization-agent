# ThermalEnvelopeSensitivity_Lab

## Summary
Sensitivity of the Lab thermal envelope & max temperature operating point. If the thermal model temperatures are more sensitive to changing losses then this factor should be increased to aid convergence.

## Description
Sensitivity of the Lab thermal envelope & max temperature operating point. If the thermal model temperatures are more sensitive to changing losses then this factor should be increased to aid convergence.
