# CustomLoss_AllowedValues_Lab

## Summary
Whether negative loss or voltage values are allowed in the Lab custom losses. When negative values are not allowed, negative values will be replaced by 0.

## Description
Whether negative loss or voltage values are allowed in the Lab custom losses. When negative values are not allowed, negative values will be replaced by 0.
