# TransientGraphUpdateDisabled

## Summary
When set to 1 then transient graphs are no longer drawn. This has to be set to 0 before last transient run during append run to show full transient results graph.

## Description
When set to 1 then transient graphs are no longer drawn. This has to be set to 0 before last transient run during append run to show full transient results graph.
