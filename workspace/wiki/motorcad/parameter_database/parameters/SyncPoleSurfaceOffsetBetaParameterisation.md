# SyncPoleSurfaceOffsetBetaParameterisation

## Summary
Controls whether the pole surface offset is a ratio or absolute parameter for SYNC ratios with beta rotor parameterisation. Absolute offset defines pole tip side instead of pole tip depth.

## Description
Controls whether the pole surface offset is a ratio or absolute parameter for SYNC ratios with beta rotor parameterisation. Absolute offset defines pole tip side instead of pole tip depth.
