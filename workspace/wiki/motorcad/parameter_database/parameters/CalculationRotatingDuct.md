# CalculationRotatingDuct

## Summary
The channel correlation or rotating channel correlation used for rotor ducts. Rotating correlation will only be used for air fluid.

## Description
The channel correlation or rotating channel correlation used for rotor ducts. Rotating correlation will only be used for air fluid.
