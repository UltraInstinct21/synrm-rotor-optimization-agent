# IMLockedRotorTorqueAverageMethod

## Summary
Method for calculating the locked rotor average torques. Improved method uses final cycle, original method uses all cycles.

## Description
Method for calculating the locked rotor average torques. Improved method uses final cycle, original method uses all cycles.
