# FEAMeasurePath_IntegralForceCorrection

## Summary
The improved method calculates the force integral taking into account the half arc length of the first and last point. The original method scales all points.

## Description
The improved method calculates the force integral taking into account the half arc length of the first and last point. The original method scales all points.
