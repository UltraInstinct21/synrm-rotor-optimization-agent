# AnsysReplaceArcEntities

## Summary
Replace Arc entities with a sweep smaller than a given value with a line entity between the start and end coordinate of the original arc entity.

## Description
Replace Arc entities with a sweep smaller than a given value with a line entity between the start and end coordinate of the original arc entity.
