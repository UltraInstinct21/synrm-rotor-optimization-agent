# DXFImportType

## Summary
The type of DXF import: 0 = Single Slot Pole, 1 = Single Rotor Pole, 2 = Single Stator Slot  +3 = Entire Machine, 4 = Entire Rotor, 5 = Entire Stator

## Description
The type of DXF import: 0 = Single Slot Pole, 1 = Single Rotor Pole, 2 = Single Stator Slot  +3 = Entire Machine, 4 = Entire Rotor, 5 = Entire Stator
