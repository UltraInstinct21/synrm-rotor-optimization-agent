## Utility functions

| set_default_instance (port)     | Set the Motor-CAD instance to use as the default when<br>running scripts from MotorCAD. |
|---------------------------------|-----------------------------------------------------------------------------------------|
| set_motorcad_exe (exe_location) | Set the path of the Motor-CAD executable file to launch.                                |
| set_server_ip (ip)              | Set the IP address of the machine that Motor-CAD is running<br>on.                      |
